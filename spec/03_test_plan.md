# 测试计划 · Global PR Agent

## 1. 测试策略
鉴于敏捷开发特性，本项目主要采用 **全链路回归测试** 与 **规则引擎一致性验证**，确保系统在无外部 API 依赖的情况下依然能输出符合预期的结果。

## 2. 核心验证项

| 模块 | 验证方法 | 预期结果 | 状态 |
|---|---|---|---|
| 自动化脚本 | `python cli.py --sample` | 产出全套 MD/JSON/DOCX 文档且内容一致 | ✅ |
| 接口服务 | `POST /api/generate-pr` | 返回符合 Pydantic 契约的完整结构化 JSON | ✅ |
| 业务控制台 | `streamlit run app.py` | 全流程 Tab 切换流畅且数据上下文保持一致 | ✅ |
| 文档渲染 | 检查生成的 DOCX | 包含所有核心生成字段且排版无破损 | ✅ |
| 兼容性检查 | `python -m compileall .` | 全量代码无语法错误 | ✅ |

## 3. 回归测试流程
1. 运行初始化脚本清理历史导出文件。
2. 执行 CLI 回归脚本并校验文件完整性。
3. 启动 API 服务，通过模拟客户端发送全流程请求并验证响应。
4. 启动交互系统，手动执行各 Agent 节点并验证人类干预逻辑。
5. 验证内容清洗组件 (`strip_research_citations`) 是否有效剔除所有源标记。
