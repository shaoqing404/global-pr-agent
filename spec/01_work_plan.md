# 工作计划 · Global PR Agent

## 1. 总体进度 (48小时开发周期)

| 阶段 | 任务 | 耗时 | 状态 |
|---|---|---|---|
| 调研 | 需求分析、Agent 链路拆解、输入契约定义 | 4h | ✅ |
| 架构 | 核心数据结构、编排引擎、接口层设计 | 6h | ✅ |
| 开发 | 报告解析、战略洞察生成、稿件生成、审核 Agent | 18h | ✅ |
| 集成 | Web 交互系统、FastAPI 接口服务、导出模块 | 8h | ✅ |
| 质量 | 全链路回归测试、文档体系补全、README 编写 | 8h | ✅ |
| 交付 | 最终版本封版与文档归档 | 4h | ✅ |
| 重构 (Pivot) | ChatBot 交互式 UX 重构与非结构化输入支持 | 8h | ⏳ |

## 2. 关键里程碑

- **M1: 契约确立** - 完成 `InformationSearchReport` 结构化输入契约定义。
- **M2: 引擎跑通** - 完成核心编排引擎 (Orchestrator) 对各 Agent 节点的逻辑串联。
- **M3: 系统交付** - 完成 Web 系统多环节交互流程开发。
- **M4: 文档齐备** - 补全技术架构、操作指南与迁移指南。
- **M5: 交互升级** - 实现纯对话驱动 (Chat-driven) 的全流程式交互体验。

## 3. 资源环境

- **系统核心**：AI Agent (Codex) + Human Operator
- **基础模型**：DeepSeek-V3 / GPT-4o
- **开发语言**：Python 3.10+
