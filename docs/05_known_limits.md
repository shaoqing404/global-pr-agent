# 已知局限说明 · Global PR Agent

## 1. 情报获取深度
当前版本系统采用预置的标准化情报报告 (`InformationSearchReport`) 模拟上游搜索 Agent 的输入。系统尚未实现全自动、实时的联网搜索与情报抓取，这可能导致部分突发舆情无法在第一时间被纳入考量。

## 2. 法律风险初筛
系统内置的 `Legal Risk Agent` 采用的是基于行业通识规则与特定合规关键词的初步筛查逻辑。该功能旨在为品牌方提供早期的风险预警，而非严谨的法律意见。正式发布前，建议由当地法律专家进行终审。

## 3. 多语言适配范围
当前系统核心展示了英文稿件及其对应的中文策略说明。虽然架构上支持扩展，但在阿联酋 (UAE) 等多语种环境下，阿拉伯语标题、正文及社媒素材的自动生成仍需进一步的语言包适配与微调。

## 4. 安全鉴权
当前系统提供的 `ACCESS_TOKEN` 鉴权主要用于展示系统接口的开放性与安全性。在真实的生产部署环境中，应接入企业级 API Gateway、SSO (单点登录)、密钥托管中心及多级权限管理系统。

## 5. UI 交互体验
目前的交互系统采用 Streamlit 构建，侧重于展现业务逻辑的闭环与 Agent 协作心智。在最终的商业化产品中，建议采用更为细腻的前端框架（如 React/Angular）以提供更佳的视觉反馈与用户交互细节。
